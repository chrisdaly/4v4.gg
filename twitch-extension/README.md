# 4v4.gg Twitch Extension

Shows the live W3Champions match overlay to viewers on your Twitch stream — player names, races, MMR chart, country flags, and AT group detection.

## How it works

- Streamer sets their battle tag in the extension config page
- Extension polls W3C API every 30s for an ongoing match
- When a 4v4 match is found, the HUD strip appears over the video for all viewers
- Disappears automatically when the match ends

## Development

```bash
cd twitch-extension
npm install
npm run build       # production build → dist/
npm run zip         # builds + creates extension.zip for upload
```

To preview the viewer locally without Twitch.ext:
```bash
npx vite preview
# then open http://localhost:4173/viewer.html?battletag=YourName%231234
```

## Registering on Twitch

1. Go to https://dev.twitch.tv/console/extensions → **Create Extension**
2. Set extension type: **Video Overlay** (and optionally **Config**)
3. In **Capabilities → Allowlist for URLs fetched by front end**, add:
   - `https://website-backend.w3champions.com/*`
   - `https://storage.w3champions.com/*`
   - `https://flagcdn.com/*`
4. In **Asset Hosting**, upload `extension.zip` (generated by `npm run zip`)
5. Set **Viewer Path** to `viewer.html` and **Config Path** to `config.html`
6. Submit for Twitch review (~1–4 weeks)

## Extension pages

| File | Purpose | Twitch field |
|------|---------|-------------|
| `viewer.html` | Transparent overlay viewers see over the stream | Viewer Path |
| `config.html` | Setup page where streamer enters their battle tag | Config Path |

## Twitch Extension config storage

The battletag is stored in Twitch's Configuration Service under the broadcaster scope:
```js
Twitch.ext.configuration.set('broadcaster', '1', JSON.stringify({ battletag: 'Name#1234' }))
```
No EBS needed — all API calls go directly from the viewer's browser to W3C servers.
